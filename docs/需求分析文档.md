# Workbition 项目需求分析文档

> **详细需求分析请参阅**: [Workbition 深度需求分析-WorkDown格式](./Workbition-深度需求分析-WorkDown.md)

## 1. 项目概述

### 1.1 项目背景
Workbition 是一款参考阿里云 Teambition 打造的团队协作与项目管理平台，旨在帮助团队高效管理项目、任务和日常工作。

### 1.2 技术栈
- **后端**: SpringBoot 3.x + Java 17+
- **前端**: React 18+ + TypeScript
- **数据库**: MySQL 8.0 + Redis
- **其他**: WebSocket（实时通信）、MinIO（文件存储）

### 1.3 项目命名
- 项目名称: **Workbition**（Work + Teambition 的结合）

## 2. 核心功能模块

### 2.1 用户与组织管理

#### 2.1.1 用户系统
- 用户注册/登录（邮箱、手机号、用户名）
- 第三方登录（GitHub、Google、微信）
- 个人资料管理（头像、昵称、签名）
- 账号安全（密码修改、二次验证）

#### 2.1.2 组织/团队管理
- 创建组织/团队
- 邀请成员（链接邀请、邮件邀请）
- 成员角色管理（所有者、管理员、成员、观察者）
- 部门/分组管理
- 组织设置（名称、Logo、公告）

#### 2.1.3 权限管理
- 基于 RBAC 的权限模型
- 项目级别权限控制
- 任务级别可见性设置
- 自定义角色与权限配置

---

### 2.2 项目管理

#### 2.2.1 项目基础功能
- 创建/编辑/归档/删除项目
- 项目分类与标签
- 项目描述与公告
- 项目模板（预设模板快速创建）
- 项目收藏与置顶

#### 2.2.2 项目成员管理
- 添加/移除项目成员
- 项目内角色分配
- 成员权限设置

#### 2.2.3 项目视图
- **看板视图**: 可视化工作流，拖拽管理任务状态
- **列表视图**: 传统列表形式展示任务
- **甘特图视图**: 项目时间线可视化，任务依赖关系
- **日历视图**: 以日历形式查看任务安排
- **表格视图**: 类似电子表格的灵活视图

---

### 2.3 任务管理

#### 2.3.1 任务基础功能
- 创建/编辑/删除任务
- 任务标题、描述（富文本编辑器）
- 任务状态流转（待办 → 进行中 → 已完成，支持自定义）
- 任务优先级（紧急、高、中、低）
- 任务截止日期与提醒
- 任务标签/分类

#### 2.3.2 任务高级功能
- 子任务管理
- 任务依赖关系（前置任务）
- 任务关联（关联其他项目任务）
- 任务模板
- 批量操作（批量分配、批量修改状态）
- 任务克隆/复制

#### 2.3.3 任务协作
- 任务评论（支持 @提及）
- 任务动态/操作日志
- 任务附件上传
- 任务关注与通知

#### 2.3.4 自定义字段
- 文本、数字、日期、单选、多选等字段类型
- 自定义字段配置
- 自定义字段筛选与排序

---

### 2.4 工作流与自动化

#### 2.4.1 自定义工作流

- 状态流转规则配置

#### 2.4.2 自动化规则

## 3. 非功能性需求

### 3.1 性能需求
- 页面加载时间 < 2秒
- API 响应时间 < 200ms（95%请求）
- 支持 1000+ 并发用户
- WebSocket 消息延迟 < 500ms

### 3.2 安全需求
- HTTPS 全站加密
- JWT + OAuth2.0 认证
- XSS/CSRF 防护
- SQL 注入防护
- 敏感数据加密存储
- 操作审计日志

### 3.3 可用性需求
- 系统可用性 > 99.9%
- 数据备份策略（每日全量 + 实时增量）
- 故障恢复时间 < 30分钟

### 3.4 可扩展性
- 微服务架构（便于后续拆分）
- 水平扩展支持
- 插件化设计

### 3.5 兼容性
- 浏览器: Chrome、Firefox、Safari、Edge（最新2个版本）
- 响应式设计: 支持桌面端和平板端
- 后续: 移动端 App

## 5. 数据库设计概要

### 5.1 核心实体关系

```
用户(User) ─┬─ 创建 ─→ 组织(Organization)
            ├─ 属于 ─→ 团队(Team)
            └─ 参与 ─→ 项目(Project)

组织(Organization) ── 包含 ──→ 项目(Project)
                           ↓
项目(Project) ── 包含 ──→ 任务列表(TaskList)
                       ↓
任务列表(TaskList) ── 包含 ──→ 任务(Task)
                            ↓
任务(Task) ── 包含 ──→ 子任务(SubTask)
                    ├── 评论(Comment)
                    ├── 附件(Attachment)
                    └── 活动日志(Activity)
```

### 5.2 主要数据表

| 表名 | 说明 | 核心字段 |
|------|------|----------|
| user | 用户表 | id, username, email, password, avatar |
| organization | 组织表 | id, name, logo, owner_id |
| org_member | 组织成员 | org_id, user_id, role |
| project | 项目表 | id, name, org_id, visibility, template |
| project_member | 项目成员 | project_id, user_id, role |
| task_list | 任务列表 | id, project_id, name, position |
| task | 任务表 | id, task_list_id, title, status, priority, assignee_id, due_date |
| subtask | 子任务表 | id, parent_task_id, title, completed |
| comment | 评论表 | id, task_id, user_id, content |
| attachment | 附件表 | id, task_id, file_url, file_name |
| activity | 活动日志 | id, project_id, task_id, user_id, action |
| custom_field | 自定义字段 | id, project_id, name, type |
| workflow | 工作流 | id, project_id, name, states |
| notification | 通知表 | id, user_id, type, content, read_status |

## 6. API 设计概要

### 6.1 RESTful API 规范

```
基础路径: /api/v1

认证相关:
POST   /auth/register          # 注册
POST   /auth/login             # 登录
POST   /auth/refresh           # 刷新Token
POST   /auth/logout            # 登出

用户相关:
GET    /users/me               # 获取当前用户
PUT    /users/me               # 更新个人信息
GET    /users/:id              # 获取用户信息

组织相关:
POST   /organizations          # 创建组织
GET    /organizations          # 获取组织列表
GET    /organizations/:id      # 获取组织详情
PUT    /organizations/:id      # 更新组织
POST   /organizations/:id/members  # 添加成员

项目相关:
POST   /projects               # 创建项目
GET    /projects               # 获取项目列表
GET    /projects/:id           # 获取项目详情
PUT    /projects/:id           # 更新项目
DELETE /projects/:id           # 删除项目

任务相关:
POST   /tasks                  # 创建任务
GET    /tasks/:id              # 获取任务详情
PUT    /tasks/:id              # 更新任务
DELETE /tasks/:id              # 删除任务
PATCH  /tasks/:id/status       # 更新任务状态
POST   /tasks/:id/comments     # 添加评论
POST   /tasks/:id/attachments  # 上传附件

工作流相关:
POST   /workflows              # 创建工作流
GET    /workflows/:id          # 获取工作流
PUT    /workflows/:id          # 更新工作流

WebSocket:
WS     /ws                     # 实时通信连接
```
