**目标**：实现完整的用户注册、登录、Token刷新、密码重置流程，用户可通过API完成认证全链路。

**开发任务**
- [x] 3.1 集成 JWT 库（jjwt-api + jjwt-impl + jjwt-jackson 0.12.6）
- [x] 3.2 实现 JWT 工具类：生成 AccessToken（2小时）、RefreshToken（7天）、解析Token、校验过期
- [x] 3.3 集成 Spring Security（spring-boot-starter-security 4.0.6）
- [x] 3.4 实现 Spring Security 配置：放行注册/登录/Swagger接口，其余需认证
- [x] 3.5 实现 JWT 认证过滤器 `JwtAuthenticationFilter`，从Header提取Token并设置SecurityContext
- [x] 3.6 实现 `POST /api/v1/auth/register` 接口：参数校验 → 密码BCrypt加密 → 写入数据库 → 返回用户信息
- [x] 3.7 实现 `POST /api/v1/auth/login` 接口：邮箱/用户名查找用户 → 密码校验 → 生成Token → 返回Token对
- [x] 3.8 实现 `POST /api/v1/auth/refresh` 接口：校验RefreshToken → 生成新Token对
- [x] 3.9 实现 `POST /api/v1/auth/logout` 接口：将Token加入Redis黑名单
- [ ] 3.10 实现 `POST /api/v1/auth/forgot-password` 接口：发送重置密码邮件（先Mock）
- [ ] 3.11 实现 `POST /api/v1/auth/reset-password` 接口：校验重置Token → 更新密码
- [x] 3.12 实现 `GET /api/v1/users/me` 接口：获取当前登录用户信息
- [x] 3.13 实现 `PUT /api/v1/users/me` 接口：更新个人信息（昵称、头像等）
- [x] 3.14 实现 `PUT /api/v1/users/me/password` 接口：修改密码（校验旧密码）
- [x] 3.15 创建统一响应体 `Result<T>` 和全局异常处理器 `GlobalExceptionHandler`
- [x] 3.16 创建 MyBatis-Plus 配置（分页插件 + 自动填充 createdAt/updatedAt）
