### 步骤 3：任务转接与委托 ⬜

**目标**：实现任务转接、委托、重新分配三种转接模式，支持审批流程。

**开发任务**
- [ ] 3.1 后端：创建任务转接表 `task_transfer`（id, task_id, transfer_type, from_user_id, to_user_id, reason, status, approver_id, approved_at, expired_at, created_at, updated_at）
- [ ] 3.2 后端：实现 `POST /api/v1/tasks/{taskId}/transfer` 发起转接（校验：发起人必须是负责人，接收人必须是项目成员）

- [ ] 3.4 后端：实现 `POST /api/v1/transfers/{transferId}/reject` 拒绝转接

- [ ] 3.6 后端：实现 `GET /api/v1/tasks/{taskId}/transfers` 获取转接历史
- [ ] 3.7 后端：实现委托模式（Delegate）：双方都有操作权限，原负责人保持
- [ ] 3.8 后端：实现重新分配模式（Reassign）：管理员直接更换负责人，无需确认

- [ ] 3.11 后端：转接操作写入操作日志

- [ ] 3.13 前端：转接待办列表（我收到的待确认转接）
- [ ] 3.14 前端：转接历史记录展示

**验证清单**
- [ ] 发起转接成功，`task_transfer` 表状态为 `pending`
