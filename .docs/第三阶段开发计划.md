### 步骤 1：任务依赖管理 ⬜

**目标**：实现任务之间的依赖关系管理，支持四种依赖类型和关键路径计算。

**开发任务**
- [ ] 1.1 后端：创建任务依赖表 `task_dependency`（id, predecessor_id, successor_id, dependency_type, lag_days）
- [ ] 1.2 后端：实现 `POST /api/v1/tasks/{taskId}/dependencies` 创建依赖关系
- [ ] 1.3 后端：实现 `GET /api/v1/tasks/{taskId}/dependencies` 获取任务依赖（前置+后续）
- [ ] 1.4 后端：实现 `DELETE /api/v1/dependencies/{dependencyId}` 删除依赖关系
- [ ] 1.5 后端：实现循环依赖检测（拓扑排序算法，创建依赖前校验）
- [ ] 1.6 后端：实现关键路径算法（CPM：正推法计算ES/EF + 逆推法计算LS/LF + 浮动时间=0为关键路径）
- [ ] 1.7 后端：实现 `GET /api/v1/projects/{projectId}/critical-path` 获取关键路径
- [ ] 1.8 后端：实现任务日期变更时自动级联更新后续任务日期
- [ ] 1.9 后端：实现里程碑管理（is_milestone标记+里程碑状态计算）
- [ ] 1.10 前端：任务详情页依赖关系面板（前置任务列表+后续任务列表）
- [ ] 1.11 前端：添加依赖弹窗（选择任务+依赖类型+延隔天数）
- [ ] 1.12 前端：循环依赖错误提示

**验证清单**
- [ ] 创建依赖关系成功，`task_dependency` 表有记录
- [ ] 循环依赖检测生效（A→B→A被拒绝）
- [ ] 四种依赖类型（FS/FF/SS/SF）均可用
- [ ] 关键路径计算正确（浮动时间为0的任务标记为关键任务）
- [ ] 前置任务日期变更后，后续任务自动级联更新
- [ ] 里程碑状态计算正确
